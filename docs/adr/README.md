Write one here when a decision gets re-litigated or when the reason behind a
non-obvious choice is not recoverable from the code. Name it
`NNNN-short-title.md` (next: `0001-`), and keep it to: the decision, the
alternatives rejected, and what would have to change for it to be revisited.
